How I Work

A monthly rhythm that prevents last-day rush

1 — Match first

Download and match GSTR-2B against books early in the cycle; chase vendor mismatches while there is still time to fix them.

2 — Review, then file

Review GSTR-3B against GSTR-1 and ledgers before filing. No return goes out unchecked.

3 — Track every due date

GST, TDS and challan dates kept on a working calendar — compliance is a schedule, not a scramble.

4 — Keep workings clean

Every reconciliation saved with clear workings in Excel / Tally, so any figure can be traced back in minutes.
